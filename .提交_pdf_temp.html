第四部分 — 校验说明

JSON 合法性：上方 JSON 内容格式正确， 已在 https://jsonlint.com/ 上检验过 已检查每一条的 evidence_quote 都来自原文。 交叉验证了 chatgpt, grok , deepseek 三个平台对 JSON 输出的数据， 发现 grok 和 deepseek 没有正确理解 requested_action 这个字段的要求， 会产生幻觉， 写一些数据集中不存在的内容进去。

第五部分 — 学习反思

编写高质量的 prompt 可以提高LLM的输出质量， 特别是 JSON 格式的数据输出， 可以对接我们日常编程的 REST 接口调用， 非常重要。 发现不同LLM平台之间的输出有一些差距， 在使用较差的LLM模型时， 需要增加额外的 prompt ： “特别是 requested_action ，如果数据集中不存在， 就写null。“， 才能纠正幻觉问题。
